🌌 IHH — Innen‑Hoch‑Himmel (iki1uc‑System)
IHH ist die Hoch‑Achse des Nord‑Quadranten im iki1uc‑Achsen‑System.
Sie bildet zusammen mit AHA (Erkenntnis) und OHO (Ober‑Hoch‑Ost) die Hoch‑Triade.

IHH steht für:

Innenwelt

Himmel / Licht / Klarheit

Ekel → AHA → Licht‑Reaktion

Wahrheit / Grenzwahrnehmung

Vertikale Nord‑Achse

IHH ist die Achse der inneren Reaktion, der Wahrnehmungs‑Schwelle und der Aufklärung.
